# EnterpriseGlue UI evidence matrix

Capture affected rows at `1440x900`; add responsive and accessibility variants
where noted.

| Surface | Minimum evidence |
|---|---|
| Login and recovery | Provider labels/chooser, local-login policy, error state, administrator recovery |
| Identity providers | List, create/edit/view, test connection, config ownership, archive, secret redaction |
| Identity mappings | All wizard steps, group choice, access target choice, saved result, disable/revoke |
| Access control | Roles, permissions, assignments, principal/resource views, Effective Access, custom role editor |
| Runtime scope | Engine Set, engine, runtime resource, runtime-resource-set, sibling and cross-tenant denial |
| Engine governance | Registration, tenancy/mode cards, backstop/sidecar settings, config-owned view state |
| Variables | Hidden, obfuscated, readable, and editable permission outcomes in Mission Control |
| Headless management | Config-lock badge, disabled mutations, configuration source, bundle apply result |
| Accessibility | Keyboard focus, announcements, horizontal tabs, 200% zoom, narrow reflow, reduced motion |

Every success screenshot must show enough surrounding page context to identify
the page, active section, selected resource, action, and persisted outcome.
